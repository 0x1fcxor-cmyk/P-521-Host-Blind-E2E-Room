Help & Documentation
Getting Started
  1. Create an identity or log in with your existing password
  2. Join a room using an invite link, or create your own room
  3. Share the invite link with others to let them join
  4. Start chatting securely with end-to-end encryption
Creating a Room

Go to the "Host Relay" tab and enter a relay URL. The system will generate a secure room key and invite link that you can share with others.

Security Features
  • P-521 Curve: High-security elliptic curve cryptography
  • E2E Encryption: Messages are encrypted end-to-end with room key
  • Blind Relay: The relay cannot decrypt your messages
  • AES-256-GCM: Authenticated encryption for message content
  • P-521 Signatures: All messages are cryptographically signed
Security Limitations
  • Relay Metadata: The relay sees IP addresses, timing, packet sizes, room IDs, and fingerprints
  • Invite Links: Room keys are included in invite links - protect them carefully
  • TOFU Trust: Trust-on-first-use model - verify fingerprints out-of-band
  • No Formal Protocol: Lacks formal protocol transcript or HKDF key schedule
  • Message Persistence: SQLite database may store message metadata in plaintext

Troubleshooting

If you're having trouble connecting to a room, make sure:

  • The relay URL is correct and includes the token
  • Your internet connection is stable
  • The relay server is online
